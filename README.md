# Stevie Clawdberg

A planned universe for [Clawd Clash](https://github.com/rodclemen/clawd-clash): your AI coding sessions as a pixel-art blockbuster battle on your macOS desktop, with characters from nine '70s–'90s adventure films (Jaws, Close Encounters, Raiders and the other Indiana Jones films, E.T., Gremlins, The Goonies, Back to the Future, Hook and Jurassic Park).

Nothing is built yet, and the name is a working title. [PLAN.md](PLAN.md) has the cast, places, set pieces, transitions and phases.
